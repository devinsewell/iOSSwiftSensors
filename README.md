# iOSSwiftSensors

Minimal SwiftUI + CoreMotion visualizer for iPhone and iPad.  
Shows live readings from all major motion and environmental sensors.

## Sensors
- Accelerometer  
- Gyroscope  
- Magnetometer  
- Gravity Vector  
- Pressure (Barometer / Altimeter)  
- Relative Altitude  

## Features
- Adaptive 2×3 full-screen grid
- Real-time gradient feedback per sensor
- Works on iOS 14 +
